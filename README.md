# 👋 안녕하세요,

사용자 요구사항을 구조화하고 서비스 흐름으로 설계하는 개발자 박상준입니다.

저는 프론트엔드 개발을 단순한 화면 구현이 아니라,
사용자의 요구사항과 행동 흐름을 이해하고 이를 실제 서비스 구조로 연결하는 역할이라고 생각합니다.

기능 구현 이전에 사용자 흐름, 데이터 구조, 상태 전이를 먼저 정의하며,
복잡한 요구사항을 이해하기 쉬운 구조로 정리하는 개발 방식을 중요하게 생각합니다.

또한 프로젝트 진행 과정에서 요구사항 정의서, 시스템 정의서, API 명세서,
ERD, 클래스 다이어그램, 활동 다이어그램 등을 직접 작성하며
기획과 개발 사이의 기준을 정리하는 역할을 수행했습니다.

사용자 경험과 시스템 구조를 함께 고민하며,
기술을 실제 문제 해결로 연결할 수 있는 개발자가 되는 것을 목표로 하고 있습니다.

## 🤟 실시간 수어 번역 통화 시스템 (프로토타입)

🔗 GitHub : https://github.com/CBNU-AI-ASURA/SignLanguageModel

### 프로젝트 목적

농인 사용자의 실시간 의사소통 문제 해결을 목표로
수어 인식 기반의 실시간 통화 시스템 프로토타입을 개발했습니다.

### 담당 역할

- 프론트엔드 개발
- Python 서버와 실시간 데이터 통신 구조 설계
- 사용자 인터페이스 및 실시간 결과 출력 구현
- AI 모델팀과의 협업 구조 정리

### 주요 구현 내용

- MediaPipe 기반 손·상체 관절 키포인트 추출 파이프라인 구현
- 관절 좌표 데이터를 시계열 데이터(CSV)로 구조화
- CNN+LSTM, GRU 기반 수어 인식 모델 학습 및 성능 검증
- Catastrophic Forgetting 문제 분석 및 개선 방향 조사
- Web 기반 영상 통화 UI 구현 및 실시간 인식 결과 오버레이 출력

### 배운 점

실시간 서비스에서는 단순 모델 성능뿐 아니라,
데이터 구조화, 지연 시간, 신뢰도 기준 설계가 매우 중요하다는 점을 경험했습니다.

또한 AI 모델팀과 프론트엔드 간 협업 과정에서
명확한 데이터 구조와 인터페이스 정의의 중요성을 배울 수 있었습니다.

## 🤖 LLM 기반 자동화 파이프라인 개발

### 프로젝트 목적

반복적인 코드 작성과 실행 작업을 자동화하기 위해
ChatGPT 및 Gemini API 기반의 자동화 프로그램을 개발했습니다.

### 주요 구현 내용

- 자연어 입력 기반 코드 생성 및 실행 파이프라인 구축
- 반복 작업 자동화를 위한 처리 흐름 설계
- 코드 실행 전 검증 로직 및 로그 기록 기능 구현
- 입력 → 처리 → 실행 단계의 표준화 구조 설계

### 성과

- 반복 작업 시간 단축
- 수작업 과정에서 발생하는 오류 감소
- 다양한 작업 요청에 대응 가능한 자동화 구조 구현

### 배운 점

단순 자동화보다 중요한 것은
반복되는 문제 자체를 구조적으로 줄일 수 있는 시스템을 설계하는 것이라는 점을 배웠습니다.
